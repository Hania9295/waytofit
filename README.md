# Way To Fit

Outil interne pour générer les programmes personnalisés des élèves Way To Fit.

## Utilisation
1. Ouvre le site (lien GitHub Pages).
2. Choisis **Diète** ou **Programme** depuis l'accueil.
3. Remplis les champs (ou utilise le prompt IA fourni pour générer automatiquement le contenu à partir de tes notes).
4. Clique sur **Exporter en PDF**.
5. Intègre le PDF dans le compte de l'élève sur l'app.

## Déploiement
Le site est un fichier `index.html` unique, sans dépendances. Il suffit de le déposer à la racine du repo et d'activer GitHub Pages (Settings > Pages > branche `main`).
